# @mirai/api-client

Generated, platform-neutral TypeScript client for `inventory-service`. Built on
[`openapi-fetch`](https://openapi-ts.dev/openapi-fetch/) and types generated by
[`openapi-typescript`](https://openapi-ts.dev/) from `packages/contracts/openapi.json`.

Per `docs/specs/client-applications.md` section 4, this package must not import browser globals,
Next.js routing, Supabase browser clients or React Native secure storage - callers inject
everything platform-specific.

## Usage

```ts
import { createApiClient } from "@mirai/api-client";

const api = createApiClient({
  baseUrl: "https://api.mirai-inventory.com",
  fetch: globalThis.fetch,
  getAccessToken: () => supabase.auth.getSession().then((s) => s.data.session?.access_token),
  onUnauthorized: () => router.push("/login"),
  correlationId: crypto.randomUUID(),
});

const { data, error } = await api.GET("/api/products/{id}", {
  params: { path: { id: productId } },
});
```

## Regenerating

Run this whenever `packages/contracts/openapi.json` changes (see its README for how to
regenerate that file first):

```
npm install
npm run generate
npm run typecheck
```

`npm run generate` rewrites `src/schema.d.ts`; it is checked into the repo like the contract
itself so a client build never depends on a live backend being reachable.
